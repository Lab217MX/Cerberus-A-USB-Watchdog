# Cerberus Display

PCB de la placa de display (OLED + botones) del proyecto Cerberus USB Watchdog.
Proyecto editable en **KiCad**.

## Archivos

### ProPrj_Cerberus_2026-09-25.kicad_pro

Archivo de proyecto de KiCad.

- **Formato:** KiCad (`.kicad_pro`)
- **Cómo abrir:** En KiCad, `Archivo → Abrir proyecto…` y seleccionar este archivo. Abre el esquemático (`.kicad_sch`) y el PCB (`.kicad_pcb`) asociados.

### ProPrj_Cerberus_2026-09-25.kicad_sch

Esquemático de la placa (conexiones del display SSD1306, botones y cabecera hacia la placa principal).

### ProPrj_Cerberus_2026-09-25.kicad_pcb

Diseño físico del PCB (placement y ruteo).

### Bibliotecas del proyecto

- `ProPrj_Cer-easyedapro.kicad_sym` — biblioteca de símbolos.
- `ProPrj_Cerberus_2026-09-25-import-fps.pretty/` — biblioteca de footprints.
- `fp-lib-table` / `sym-lib-table` — tablas de bibliotecas de KiCad.
